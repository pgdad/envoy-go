**What this phase is.** Phase 56 is the **NINTH Observability-family row** (after gRPC-ALS @44, OTLP-log @45, tracing @46, metrics_service @47, statsd @48, dog_statsd @49/@50, statsd-tcp @55). It lands Envoy's HTTP tap filter `envoy.filters.http.tap` — a per-stream **dual-sided observer** filter that compiles a `config/common/matcher/v3.MatchPredicate` proto tree into a tri-state node tree, evaluates it incrementally over request+response headers, and — at stream end, on a match — writes a byte-exact buffered-JSON `data/tap/v3.TraceWrapper` (an `HttpBufferedTrace`) to a per-stream `file_per_tap` sink. It is the FIRST Observability row to integrate at the HTTP-filter layer (not the bootstrap-sink layer) and the FIRST filter whose emit decision is deferred to stream end across BOTH directions. It adds TWO library packages (`internal/headermatch`, `internal/matchpredicate`) + the filter package `internal/filter/http/tap` (which houses the sink), and ZERO new go.mod modules (all tap protos resolve at the pinned `go-control-plane/envoy v1.32.4`). The family STAYS OPEN.

**The SPEC's amendments (twelve `AMEND-TAP-*`, each forced by a live probe).**

- **AMEND-TAP-BODY** (LOAD-BEARING — decides the fixture): the reference always captures bodies, but a ZERO-LENGTH body OMITS the `body` field ⇒ a bodyless `GET` → `204` yields a structurally headers-only trace on BOTH sides; `0099` MUST drive GET→204.
- **AMEND-TAP-NOEARLYEMIT**: the `orshort` probe proves the reference NEVER early-emits — the trace is always the WHOLE stream at stream end; the charter's flagged-but-unsettled §2.6 nuance is dissolved.
- **AMEND-TAP-JSON**: byte-exact `protojson` with `EmitDefaultValues` (NOT `EmitUnpopulated`) + a trailing `\n`.
- **AMEND-TAP-PSEUDO**: `:scheme` never reaches the filter map; `:status` not in the encode map (use the ADR-0196 accessor); the `ReconcileOrderedHeaders` wire-leak trap (inject `:status` into a COPY only); lowercase every key; no stable iteration order.
- **AMEND-TAP-PRECEDENCE**: `match` wins over the DEPRECATED `match_config`; NEITHER-set is a NEW parity boot-reject.
- **AMEND-TAP-TAPENABLED**: `TapConfig.tap_enabled` (f3) — an unhandled field the charter never mentioned; observed INERT; envoy-go rejects it.
- **AMEND-TAP-REJECTS**: the PARITY-vs-DEPARTURE reject taxonomy; a `streaming_grpc` sink ABORTS the reference process (exit 139).
- **AMEND-TAP-SINKS**: PGV requires exactly ONE sink (0 and 2 both boot-reject).
- **AMEND-TAP-ARMCOUNT**: HeaderMatcher = 8 oneof arms; rbac handles 8 (not 11); csrf/hcm are comments-only.
- **AMEND-TAP-FILTERCOUNT**: 20 registered → 21; 19 production → 20 (the charter's "19 → 20" is imprecise).
- **AMEND-TAP-FREEZE**: the HTTP registry is frozen at `internal/boot/boot.go:65`, NOT main.go.
- **AMEND-TAP-PROTOPATHS**: three distinct `common.pb.go`s; two distinct `MatchPredicate` protos; `TraceWrapper` is a 4-arm oneof.

**The differential proof (a glob-and-decode headers-only trace comparison).** ONE fixture (56.1): `0099-http-tap-headers` — an HCM + tap matching `and_match{[http_request_headers_match(x-tap==yes), http_response_headers_match(:status==204)]}`, a `file_per_tap` sink to a per-side temp dir, `JSON_BODY_AS_STRING`. The driver drives N matching (`x-tap: yes`) + M non-matching (`x-tap: no`) **bodyless GET**s against a **204** backend ⇒ headers-only traces on BOTH sides. Assertions: glob `<path_prefix>*`, decode each as `TraceWrapper` (`reference_streaming_sink_differential_framing` — compare the PAYLOAD, never filenames/framing); trace count == N; `rq_tapped` == N; `request.headers`/`response.headers` ⊇ a named lowercased subset; `request.body`/`response.body` ABSENT; `trailers == []`; `downstream_connection` ABSENT; NO trace for non-matching streams. Four deliberate breaks (each `-count=1`, `t.Errorf`-per-property): emit-at-decode, predicate-always-true, `EmitUnpopulated`, populate-trailers. BackendKind stays 38.
