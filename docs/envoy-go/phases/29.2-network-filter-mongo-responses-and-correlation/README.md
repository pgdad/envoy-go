- (d) **dynamic-metadata emission** (`emit_dynamic_metadata` → the ADR-0217 Bucket; collection-keyed operation lists; per-pass clear; differential-invisible → unit-test proof + a coverage note).
- (e) Fixture **`0051-mongo-responses`** (cross-side `StatsAsserter`; the new `TCPMongoResponder` backend emitting correlated OP_REPLY bytes; the gauge asserted at quiesced points; the `cx_destroy_*` PRESENCE-ONLY arms) + the R4 deliberate-break.

- (g) The **completion bundle**: ADR-0225 §Decision/§Consequences body in place + the §Context AMEND recording the D-P4 coverage-boundary re-scope; the BEHAVIOR_CONTRACT 29.2 bundle (incl. the dynamic-HISTOGRAM coverage boundary + the D-P4 close-direction boundary + the dynamic-metadata note); the six-gate; STATE/ROADMAP advance (sub-row 29.2 `in-progress → done`; **parent row 29 STAYS `in-progress`** — the ROLLUP is 29.3's).
