**What this phase is.** A SEPARATE concurrent `hedgeExecutorH1`/`hedgeExecutorH2` (`internal/filter/http/router/hedge.go` — a sibling to `retry.go`; NO existing executor is modified) dispatched via the `H{1,2}ClusterAction` (+ weighted) closure switch — the hedge branch BEFORE the `if a.rp != nil` retry branch, gated by `(*HedgePolicy).TriggersConcurrency()`. Each in-flight attempt is a goroutine (body replay + `do{H1,H2}ClusterAction` + `matches` classify + the CB-admission/`RecordUpstreamResult`/`retry_budget` seams), with a per-attempt HEDGE-TRIGGER timer (`time.AfterFunc` at `per_try_timeout`) that on expiry launches a budget-counted hedge LEAVING the original in flight; a BUFFERED first-acceptable-wins collector returns the first non-retriable result + cancels/drains the losers (no leak, `-race`-clean). Parsed from `RouteAction.hedge_policy` (`route.v3.HedgePolicy`, field 27) with the `VirtualHost.hedge_policy` (field 17) route-absent fallback, carried on `clusterRouteAction.hedgePolicy`. NO new stat (a hedge reuses the 42.1 `upstream_rq_retry*` counters); byte-identical when no triggering `hedge_policy` (a nil/non-triggering guard, proven by the full 78→79-dir differential held GREEN).

**The load-bearing invariants (SPEC §1.1 AMEND-H1..7 — guarded at every review):**
- **AMEND-H1 (the #1 invariant)** — a hedged per-try-timeout increments `upstream_rq_retry` (+ `_retry_backoff_exponential`, NO `time.Sleep`), NEVER `upstream_rq_per_try_timeout` (which STAYS **0** under hedge mode — the per-try-timeout is a hedge-LAUNCH, not an abandonment). The `hedgeExecutor` uses a HEDGE-TRIGGER timer, NOT the 42.2a cancelling-deadline-+-discriminator, so it never touches the per-try-timeout counter. The `0077` Break B (`IncUpstreamRqPerTryTimeout` in the hedge path ⇒ `upstream_rq_per_try_timeout != 0` cross-side ⇒ fail) + a unit test are the proofs.
- **AMEND-H2** — `upstream_rq_retry_limit_exceeded` under hedging means "no more hedges can launch", NOT a final failure: the in-flight original can still WIN with a 200. Hedging RECOVERS a slow request where 42.2a sequential ABANDONS it to a 504.
- **The H1/H2 loser-cancel ASYMMETRY (D-S422B-2, a recorded departure)** — `doH1ClusterAction` honors only `ctx.Deadline()` (NOT `ctx.Done()`), so an H1 loser completes on backend-response (the `0077` `/__release` guarantees termination — NO active H1-loser socket reset); `doH2ClusterAction`'s `RoundTrip(ctx)` honors `ctx.Done()`, so an H2 loser aborts promptly. The driver code stays UNCHANGED (reused concurrently).
- **Concurrency hygiene (PLAN I1)** — the `time.AfterFunc` callback is a PURE non-blocking `hedgeReq <- struct{}{}` send; the COLLECTOR LOOP is the SOLE mutator of `hedgesLaunched`/`limitExceededOnce` + the SOLE caller of `Inc*`/`TryAcquireRetry`/`launch`. The result + hedgeReq channels are BUFFERED to `int(hp.InitialRequests)+maxHedges+1` (no loser blocks on send ⇒ no leak). `-race`-clean.
- **Budget-counted fan-out (D-S422B-3, AMEND-H4)** — the `initial_requests`/`additional_request_chance` fan-out is reference-no-op'd ⇒ SUBJECT-SIDE only (a recorded departure; UNIT-tested — NO `0078` dir); 1 primary (not a retry) + (initial−1) + an optional deterministic-draw extra, each `TryAcquireRetry`-gated BEFORE the goroutine spawn (acquire-gates-spawn caps the live goroutine count under the `retry_budget`).
- **AMEND-H5** — NO new stat; the surface STAYS **1181** (`EnsureRetryStats` is called when `TriggersConcurrency()` even with no `retry_policy`).

**The differential proof.** `0077-hedge-on-per-try-timeout` (cross-side; H1-only; REUSE `BlockingHoldResponder` — NO new BackendKind): a SINGLE held host past a small `per_try_timeout` ⇒ the original + N hedges all launch concurrently; fire `/hedge` in a goroutine, poll-to-converge on `upstream_rq_retry == N && upstream_rq_retry_limit_exceeded == 1` (the release barrier — NEVER a `time.Sleep`), `/__release` ⇒ the first-acceptable 200; cross-side EXACT (single host, offset-irrelevant): `upstream_rq_retry == N`, **`upstream_rq_per_try_timeout == 0`** (the AMEND-H1 keystone), `upstream_rq_retry_limit_exceeded == 1`, `upstream_rq_total == N+1`, `downstream_rq_2xx == 1`, final 200. 2 `-count=1` deliberate breaks (A: neutered hedge-launch ⇒ `upstream_rq_retry` never converges to N; B: `IncUpstreamRqPerTryTimeout` in the hedge path ⇒ the `per_try_timeout == 0` assertion fails) + 20/20 flake-free + `-race`-clean.
