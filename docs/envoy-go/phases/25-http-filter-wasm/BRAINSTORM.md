### 1.4 ADR-0045 split-by-surface readiness — HIGH at BRAINSTORM; 3-way pre-split chosen per Q1

Per ADR-0045 §6, the split-gate fires when `PLAN.md > ~25 tasks OR > ~1500 LoC estimated`. Phase 25's full-parity surface is anticipated to exceed BOTH gates substantially: (a) the NEW `internal/wasm/` framework primitive alone (wazero VM lifecycle + compile cache + sandbox config + ABI-registration interface + the in-house proxy-wasm v0.2.1 host ABI implementation for ~40+ host functions) is ~2500-3500 LoC at full surface (substantially larger than phase-22's `internal/lua/` ~600-900 LoC because proxy-wasm v0.2.1 is a much larger ABI than the gopher-lua bridge surface); (b) the `internal/filter/http/wasm/` package across all 3 sub-phases is anticipated at ~2500-3500 LoC (envelope matches phase-22 ext_authz scope but adds the multi-plugin VM-sharing path + the per-route 3-tier dispatch); (c) the per-sub-phase task counts are anticipated at 14-18 per sub-phase × 3 sub-phases = 42-54 tasks total. Total anticipated LoC ~5000-7000, task count ~42-54 — both far above the ADR-0045 split-gate; substantially larger than phase-22 lua's anticipated ~3500-5000 LoC + ~42-54 tasks.

The user picked the 3-way pre-split at Q1 (rather than the full-parity-single-phase-with-PLAN-time-split-gate or the MVP-slice-single-phase approaches). The 3-way split axes are natural and FEATURE-PROGRESSIVE (per Q7): 25.1 = primitive + headers-only HTTP bridge; 25.2 = body + advanced hostcalls (timer + metrics + shared data + httpCall + foreign-function default-deny + full stream-info); 25.3 = per-route + multi-plugin VM-sharing + conformance harness seed. Each sub-phase is independently shippable + delivers operator-visible value: 25.1 ships a usable WASM filter (header mutation + log + local-response short-circuit); 25.2 extends with body access + outbound HTTP calls + metrics + timer dispatch; 25.3 extends with per-route routing + multi-plugin operator ergonomics + the conformance-harness signal.
