## 1. Purpose / Mission

Phase 66 delivered `combined_validation_context` (CVC) by **pool substitution** (ADR-0287, Design A): the SDS-delivered dynamic pool wins outright and `default_validation_context.trusted_ca` is NEVER read. Phase 68 closes it.
