CONTRADICTS BRAINSTORM Decision 3 hypothesis (which expected Envoy parity = no method check, mirroring 08.1's read-only-endpoint posture per ADR-0090). ADR-0093 consequently partially amends ADR-0090's no-method-discrimination posture: **mutating endpoints DO get method discrimination; read-only endpoints continue to accept any method** (`/drain_listeners` is the FIRST envoy-go endpoint with 405 enforcement); (5) new connections during drain receive accept-then-FIN — TCP 3-way handshake completes; the server immediately closes with FIN without writing any HTTP response (curl error 52 "Empty reply from server").
