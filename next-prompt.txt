- **THE fan-out is BUDGET-COUNTED (Q-fanout-budget — the one residual fork, SETTLED):** the reference no-ops `initial_requests`/`additional_request_chance` (`#not-implemented-hide:`), so their concurrency/budget semantics are a PURE envoy-go design choice. The first of N initial requests is the PRIMARY (not a retry); each ADDITIONAL fan-out attempt draws `TryAcquireRetry` + bumps `upstream_rq_retry`, capped by `num_retries` + the `retry_budget`. CONSEQUENCE: the budget CAPS the goroutine fan-out (a degenerate `initial_requests:1000` cannot spawn 1000 goroutines) PROVIDED the `TryAcquireRetry` grant GATES the spawn (acquire-then-spawn — an explicit PLAN/SPEC constraint, NOT automatic).
- **THE HIGHEST-RISK pin — D-H-RACE (the NEW as-built wrinkle the parent could not foresee):** the concurrent collector's loser-cancellation must NOT trip the race-robust per-try-timeout discriminator into a false synthesized-504/`IncUpstreamRqPerTryTimeout()`. The as-built discriminator does NOT automatically defend: the `<failure-guard>` (`localOrigin`/`Status==0`) is TRUE for a cancelled in-flight attempt, and the wall-clock fallback `!time.Now().Before(attemptDeadline)` fires on deadline-ELAPSE regardless of the cancel cause — so a SLOW loser the collector reaps AFTER its own deadline would falsely fire. The `ctx.Err()==nil` parent-alive guard only suppresses if losers are cancelled via an ANCESTOR of the per-attempt `ctx` (NOT the child `attemptCtx`). The 42.2b SPEC MUST pin ONE of three mitigations: (a) cancel losers via a hedge-scoped parent ctx so `ctx.Err()!=nil` short-circuits; (b) an explicit collector-cancel sentinel the discriminator checks BEFORE the wall-clock fallback; (c) suppress the per-try-timeout accounting for any collector-abandoned attempt.
- **Split verification (SPLIT-BY-FIELD):** `hedge_on_per_try_timeout` CROSS-SIDE (the reference implements it); the `initial_requests`/`additional_request_chance` fan-out SUBJECT-SIDE (a recorded departure — the reference fires exactly 1 initial request; the offset-invariant downstream-2xx outcome stays cross-checkable).
