⚠️ **NORMALIZE THE PATH FORM BEFORE COMPARING ARMS** (wrapped prints bare paths, GNU prints `./`-prefixed). ⚠️ **Print FILE NAMES, never a count.** ⚠️ **`git check-ignore` REASSURES YOU WRONGLY** — git exempts TRACKED files, so it exits 1 and reads as *"not ignored"*; `git check-ignore -v --no-index` prints the truth (`.gitignore:2:next-prompt.txt`), and `git status` is the discriminating check. ⚠️ **`command grep` DOES NOT SURVIVE `xargs`** (`xargs` execs a binary; `command` is a shell keyword) — inside `xargs` use `git grep` or `/usr/bin/grep`. ⚠️ **`grep -c` ON ZERO MATCHES IS TOOL-SPECIFIC**: only `git grep -c` prints nothing; GNU and the wrapper print `0`.
