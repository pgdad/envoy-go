## An IMPL finding recorded at phase 49 (worth surfacing if a future row's differential asserts a wire-name-collapsed stat cross-side)
- **A wire-name tag-collision discovered during the `0093` differential:** the bootstrap's ADMIN interface runs its own internal HTTP connection manager (`stat_prefix "admin"`), which — via `stats.ExtractTags`'s SN2 hoist — collapses to the SAME residual wire name as a TEST LISTENER'S own HCM stats (e.g. both become `http.downstream_rq_total`/`http.downstream_rq_xx`), differing ONLY in the `envoy.http_conn_manager_prefix` tag VALUE (`"admin"` vs the test listener's own prefix). The reference container's own `wait.ForHTTP("/ready")` startup poll is itself one such `admin`-tagged request, so a plain per-name `DeltaSum` never converges to exactly K (observed stuck at K+1 — the extra request is baked into the first flush's delta permanently). Fixed via an ADDITIVE `statsdrecv.Server.DeltaSumTagged(name, tags)` accessor (an EXACT-tag-set-keyed running sum, alongside the existing name-only `DeltaSum`) — no production code change, just a driver/receiver-side disambiguation. **Reuse this for any future row whose differential asserts a stat name that ALSO exists (under a different tag) on the bootstrap's own admin interface** — a plain name-keyed assertion will be silently contaminated by the admin readiness probe.
