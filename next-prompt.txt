## Architecture as SPEC'd (43.2a — ADR-0253; SUPERSEDES ADR-0056)

**THE load-bearing SPEC finding (AMEND-H2-1 — the §11 live probe, USER-CONFIRMED, REVERSED the BRAINSTORM):** reference Envoy's multi-conn H2 pooling keys off the cluster's OWN `http2_protocol_options.max_concurrent_streams` (the LOCAL cap), NOT the peer's advertised SETTINGS — with cluster cap C + K held streams it opens EXACTLY `ceil(K/C)` upstream conns (deterministic, zero errors ⇒ cross-side EXACT differential, NOT a 43.1-style robust-only departure); peer-SETTINGS-only ⇒ pack-onto-1-conn + the backend REFUSES the excess (`503 REFUSED_STREAM`, no reactive reconnect). So the local cap (BRAINSTORM-deferred) is PULLED INTO 43.2a scope. **The design:** a new `internal/cluster/h2pool.go` — `c.h2Pool map[string][]*pooledH2Conn` (keyed by `ep.Addr()`, guarded by `h2PoolMu`; symmetric with `h1Pool`) + `pooledH2Conn{cc *h2.ClientConn; inFlight int}`. `AcquireH2Stream(ctx)` → stream HIT (multiplex onto a `!closed() && inFlight<cap` conn, NO permit) / conn MISS (`acquireConnSlot` → dial a fresh `ClientConn` per the refactored `DialH2` internals, or PEND on the stream-aware queue) / queue-full (`IsConnPoolOverflow` → the router's existing 503 branch). `releaseStream` decrements `inFlight`, hands a freed slot to a queued waiter (no new conn) or eager-closes a `closed() && inFlight==0` conn (releasing the 43.1 permit). The per-conn cap = the cluster's `http2_protocol_options.max_concurrent_streams` (parsed onto `Cluster`, default HIGH per AMEND-H2-3 ⇒ single-conn multiplex unless configured). The stream-aware pending queue is a SEPARATE structure from the 43.1 `connPool.waiters` (the 43.1 queue wakes on conn-permit-release ONLY; the H2 queue ALSO wakes on stream-free), reusing the 43.1 `sync.Mutex`+FIFO+buffered-cap-1 wake PATTERN, bounded by `max_pending_requests`. Minimal liveness only (closed-skip + evict-on-RoundTrip-error); graceful GOAWAY drain is 43.2b. The router rewire replaces `defer cc.Close()` with `AcquireH2Stream`+`releaseStream` at BOTH H2 sites. **Stats (AMEND-H2-2):** add `upstream_cx_http2_total` (counter) + `http2.streams_active` (gauge) — there is NO `upstream_cx_http2_active`; stat surface **1183 → 1185**.
