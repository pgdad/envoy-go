## Empirical pins the 28.1b SPEC must know (established this session)

1. The dynamic auth counter shape is `<stat_prefix>.zookeeper.auth.<scheme>_rq` (scope-implicit `.zookeeper.`).
2. Upstream collapses non-builtin auth schemes into `auth.unknown_scheme_rq` (builtins: `auth`/`digest`/`host`/`ip`/`ping_response`/`world`/`x509`).
3. The real ZK auth frame layout is `xid + opcode + type + schemeLen + scheme + credLen` (floor 20 bytes).
4. A SetAuth DATA request (positive xid, opcode 100) is a DECODE ERROR upstream (no switch case).
5. The upstream `setauth_*` counter family exists in the macro but is NEVER incremented.
